# linearsoftwarefactory

An autonomous software factory driven by Linear team LOO. Put an idea in **Backlog**; the factory plans it into build and test issues, builds independent issues in parallel, tests each one with separate agents, repairs failures, and integrates verified work directly into `main`.

See [docs/FACTORY.md](docs/FACTORY.md) for the workflow, the Linear mapping, and recovery rules. Run `bun test` for the full suite.
